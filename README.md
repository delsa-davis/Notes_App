# Notes App

A simple and clean Notes App built with Flutter as part of a Flutter internship coding assignment.

## Features

* Create new notes
* View notes
* Edit existing notes
* Delete notes with confirmation
* Form validation for title and description
* Empty state when no notes are available

## Tech Stack

* Flutter
* Dart

## Getting Started

### Prerequisites

* Flutter SDK
* Dart SDK

## Project Structure

```text
lib/
├── controllers/
├── models/
├── screens/
└── widgets/
```
## Conclusion

The Notes App provides a simple and intuitive way to create, view, edit, and delete notes, with a clean interface and straightforward user experience.
